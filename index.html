PROJECT INFORMATION

About CyberShield AI

Academic cybersecurity awareness & threat analysis platform.

CyberShield AI

Detect threats. Understand risks. Stay protected.

CyberShield AI is a browser-based cybersecurity demonstration platform designed to analyze email text, website URLs and file metadata for common suspicious patterns. It assigns heuristic risk scores and provides educational explanations of detected indicators.

Project Objectives

  • Improve awareness of phishing and suspicious links.
  • Demonstrate automated risk scoring.
  • Explain potential threat indicators.
  • Provide scan history and reports.
  • Demonstrate front-end web development skills.

Technology Stack

HTML5CSS3JavaScriptLocalStorageWeb Crypto APIChart.js

Limitations

This project uses local heuristic rules, not a trained machine-learning model. It does not connect to threat-intelligence databases, execute files, upload files, or verify whether a website is safe. Results should not be considered definitive security advice.
